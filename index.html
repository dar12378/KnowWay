Privacy and permissions

Private by default

No user should see another person’s full graph without permission.

Need-to-know access

Users should see only what is required to complete the intro safely.

Audit-ready mindset

In production, every sensitive action must be logged.

Data types in profile

Email, phone, company, and sub-contacts can exist in the profile, but should only be visible to authorized roles.

Security starter

Local-first demo only

This MVP stores data in localStorage. For production use a secure backend, authentication, encryption, and server-side permission checks.

No false promises

No system can guarantee zero bugs forever. The right approach is least exposure, least privilege, and defense in depth.
